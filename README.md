# ☕ CAGONG

**カフェの窓際で勉強しているような気分になれる、macOS の勉強タイマーです。**

東京の夕焼け、パリの街角、セーヌ川の夜。好きな景色を背景に、お気に入りのドリンクを一杯置いて、
今日やることを書いたら「開始」を押すだけ。勉強した時間は月間カレンダーにたまり、友達がいま
勉強しているかどうかも見えます。

![勉強画面](docs/screenshots/timer.jpg)

## できること

### ⏱ 開いて、押すだけ

アプリを開くと、日付はもう今日に合わせてあります。TODO を書いて開始を押せば計測が始まります。

- **一日の目標** — `목표 4시간 중 40%`（目標4時間のうち40%）の表示を押すと、その日の目標を変えられます。試験前と週末で同じ目標である必要はありません
- **メモ用紙の TODO** — 毎日やることは画鋲で固定しておくと、翌日も最初から載っています
- **日付をまたいでも大丈夫** — 夜に始めて深夜2時まで続けても、時間はすべて始めた日に入ります
- **閉じても続きから** — アプリを閉じて開き直しても、計測画面に戻ってきます（閉じていた間の時間は数えません）

### 📅 1か月をひと目で

![月間画面](docs/screenshots/monthly.jpg)

日付のマスには、その日に勉強した時間が入ります。マスは目標に対する達成度に合わせて下から満たされます。
上には月の合計・勉強した日数・一日平均が並びます。日付を押すと、**何時に座って何時に切り上げたか**と、
その日の TODO まで振り返れます。

### 👥 友達と一緒に

![友達画面](docs/screenshots/friends.jpg)

招待コードで友達を追加し、相手が承認すればお互いの友達になります。友達がいま勉強中かどうかや今日の進み具合が
一覧で見えます。友達が勉強を始めたとき、目標の半分・全部を達成したとき、その日の勉強を終えたときには通知が届きます。
（画像の友達の名前はぼかしています）

### 🎨 好きな雰囲気で

- **テーマ3種** — 実際のカフェ写真を背景にする `사진 카페`（写真カフェ）、クラフト紙とエスプレッソの
  `웜 카페`（ウォームカフェ）、デスクライトひとつだけの `심야 스탠드`（深夜のデスクライト）
- **背景写真** — パリの夏、モンマルトルのカフェ、東京の夕焼け、セーヌ川の夜。`⌘←` `⌘→` で切り替えられ、自分の写真も追加できます
- **ドリンク6種** — Espresso、Americano、Cafe Latte、Matcha Latte、Lemonade、Chocolate Frappuccino。
  計測中はホットドリンクから湯気が立ちのぼるので、数字を見なくても状態がわかります

## こだわったところ

**クリックを一度も取りこぼさない**
保存はバックグラウンドのキューで行い、メインスレッドは値をコピーして渡すだけにしました。
クリック1回あたりの処理が 9.5ms から 0.04ms になり、記録が3年分たまっても1フレーム（16.6ms）を超えません。
計測中の画面全体の再描画も、毎秒3回から0回に減らしました。

**押したつもりの場所が、ちゃんと押せる**
SwiftUI は描画された部分しかクリック領域にしないため、矢印ボタンで実際に押せるのは見た目の7%だけでした。
共通のボタンスタイル3つに `contentShape` を付け、アプリのすべてのボタンを一度に直しました。

**記録が消えない**
ユーザーの操作はすぐにディスクへ書き込み、一時停止・終了・アプリ切り替えのときは同期で確実に保存します。
日付の帰属や保存タイミング、旧形式の移行などは、81件の動作検証（`Tools/StoreTest.swift`）で確かめています。

## はじめかた

```bash
./build.sh --run
```

`build/CAGONG.app` が作られて起動します。Command Line Tools さえあれば、Xcode は不要です。
Xcode を使う場合は `Package.swift` を開いて ⌘R で実行できます。

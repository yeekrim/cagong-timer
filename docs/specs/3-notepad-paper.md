# 공부 탭 메모지 스타일과 드래그

UUIDv7: 01a1ddb6-62a5-77fb-87ed-d7a6efcfcc9d

## 승인된 SPEC
- 공부 탭의 자유 메모를 TODO 바로 아래에 고정한다. 드래그는 추가하지 않는다.
- TODO와 종이, 테이프, 기울기, 그림자 스타일을 공유한다. 겹치는 경우 메모장이 앞에 보이게 한다.
- 기존 로컬 메모 편집과 시작·종료 저장 동작을 유지한다.
- 메모 기능이 기본 브랜치에 없으므로 기존 메모 기능에 필요한 변경만 포함한다.
- 빌드 및 배치와 저장을 검증하고, 친구 탭 수정도 포함하는 로컬 미리보기를 갱신한다.
- 이슈, 기존 단계 라벨 갱신, 전용 worktree, SPEC, 커밋, 푸시, PR이 승인됐다.

## 승인된 타이머 카드 배치 수정
- 기존 좌우 배치에서 왼쪽 타이머 카드의 세로 중앙을 오른쪽 TODO와 메모 사이에 맞춘다.
- 오른쪽 메모지의 순서와 스타일, 날짜 표시의 배치, 좁은 창의 세로 배치를 유지한다.
- 기본 창 크기의 배치와 빌드를 확인하고 기존 PR과 통합 미리보기에 반영한다.

## 승인된 공부 화면 고정
- 공부 탭의 바깥 스크롤을 제거한다. 긴 메모는 본문 안에서만 스크롤한다.
- 좁거나 낮은 창에서는 공부 화면 배치를 가용 영역 안에 맞춰 주요 조작부가 잘리지 않게 한다.
- 먼슬리와 친구 탭의 기존 스크롤을 유지한다.
- 기본 크기와 좁은 창의 배치를 확인하고 기존 PR과 통합 미리보기에 반영한다.

## 승인된 타이머 중앙 고정
- 왼쪽 타이머 카드를 공부 본문 영역의 세로 중앙에 고정한다. 오른쪽 TODO와 메모 사이의 틈은 배치 기준에서 제외한다.
- 기본 창과 최소 창 크기에서 TODO 항목 수를 바꿔도 타이머 카드의 세로 중앙이 일정한지 확인한다.
- 기존 PR과 통합 미리보기를 갱신한다.
